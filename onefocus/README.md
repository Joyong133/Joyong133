# 🎯 원앱 집중 (OneFocus) — 안드로이드 앱

앱 하나를 고르면 **탭 1000회(횟수 변경 가능)** 를 채우거나 **타이머가 끝날 때까지**
다른 앱을 실행하거나 그 앱에서 나갈 수 없게 잠가 주는 안드로이드 앱입니다.

## 설치

1. 휴대폰에서 **[OneFocus.apk 받기](https://github.com/joyong133/Joyong133/releases/download/onefocus-latest/OneFocus.apk)**
   (또는 저장소 **Releases → 원앱 집중 APK (최신 빌드)**).
2. 받은 파일을 열어 설치합니다. "출처를 알 수 없는 앱" 경고가 나오면 설치를 허용하세요.
3. **원앱 집중** 을 열고 **접근성 설정 열기 → 설치된 앱 → 원앱 집중 잠금** 을 켭니다.
   - 안드로이드 13 이상에서 "제한된 설정" 때문에 켜지지 않으면:
     앱 안의 **앱 정보 열기** → 오른쪽 위 **⋮** → **제한된 설정 허용** 후 다시 켜세요.

## 사용법

1. **집중할 앱** 을 고릅니다 (검색 가능).
2. **끝나는 조건** 을 고릅니다.
   - **탭 횟수**: 화면을 N번(기본 1000번) 터치하면 끝
   - **타이머**: N분(기본 25분)이 지나면 끝
3. **집중 시작** → 선택한 앱이 열리고, 화면 위쪽에 남은 탭/시간이 표시됩니다(끌어서 옮길 수 있음).

집중 중에는

- 홈 버튼, 최근 앱, 뒤로가기로 앱을 나가면 🔒 차단 화면이 뜨고 선택한 앱이 바로 다시 열립니다.
- 다른 앱(설정 포함)은 열 수 없고, 알림창을 내리면 바로 닫힙니다.
- 전화(기본 전화 앱·수신 화면), 키보드, 권한 팝업은 그대로 쓸 수 있습니다.
- 휴대폰을 껐다 켜도 세션이 이어집니다. 중간에 끄는 버튼은 없습니다.

## 동작 방식

- `FocusService` (접근성 서비스): 앞에 나온 창의 앱 이름을 보고, 선택한 앱이 아니면
  전체 화면 차단막을 띄우고 선택한 앱을 다시 실행합니다. 화면 내용이나 입력 글자는 읽지 않습니다.
- 탭 세기: 작은 상태 표시 창이 `FLAG_WATCH_OUTSIDE_TOUCH` 로 화면 터치마다 신호를 받아 1회씩 셉니다.
- 진행 상태는 `SharedPreferences` 에 저장됩니다.

## 빌드

`onefocus/` 아래를 바꿔 푸시하면 GitHub Actions(`.github/workflows/onefocus-apk.yml`)가
APK를 빌드해 `onefocus-latest` 릴리스에 올립니다. 직접 빌드하려면 Android SDK가 설치된 PC에서:

```bash
cd onefocus
./gradlew assembleRelease   # → app/build/outputs/apk/release/app-release.apk
```

서명 키(`app/onefocus.keystore`, 비밀번호 `onefocus`)는 업데이트 설치가 되도록 저장소에 넣어 둔 개인용 키입니다.
