# 안심메시지 (SMS Blocker)

> 문자 + 전화 차단. 차단 번호는 문자와 전화에 함께 적용됩니다.

차단한 번호에서 온 문자를 **아예 저장하지 않는** 안드로이드 기본 SMS 앱입니다.
일반 메시지 앱은 시스템에 저장된 문자를 그대로 보여주기 때문에, 외부 앱으로는
차단 문자를 숨길 수 없습니다. 이 앱은 **스스로 "기본 SMS 앱"이 되어** 수신 문자를
직접 처리하고, 차단 번호의 문자는 시스템 저장소에 쓰지 않습니다. 그래서 어디에도
나타나지 않습니다.

## 화면 / 기능

- **대화 목록**: 사람별 대화, 연락처 이름, 마지막 문자, 안 읽은 개수. 길게 누르면 차단/삭제.
  - 🔍 **검색**: 이름·번호·문자 내용.
  - ⋮ → **모두 읽음으로 표시**.
- **대화 화면**: 말풍선 채팅, 날짜 구분, 보내기(전송 중/실패 표시), 링크·전화번호 터치, **글자 수 표시**.
  - 말풍선 길게 누르기 → **복사 / 전달 / 삭제**, 실패한 문자는 눌러서 **다시 보내기**.
  - ⋮ → 전화 걸기 / 이 번호 차단(해제) / 대화 삭제.
- **새 메시지**: 오른쪽 아래 버튼 → 번호 입력 또는 **연락처에서 선택**.
- **알림에서 바로 답장 / 읽음**.
- **통화 거절 문자**: 전화 올 때 "문자로 거절"을 누르면 이 앱이 보냅니다.
- **차단 관리**(⋮): 번호·발신자 이름 차단, **번호 패턴 차단**, **문구 차단**(예: 대출, 광고), 전화 차단 설정.
  - **번호 패턴**: 숫자 3자리 이상(예: `070`)을 넣으면 그 숫자가 들어간 모든 번호의 **문자와 전화**를 차단.
    기본은 '포함'(번호 어디에 있어도 차단), '앞자리만'을 체크하면 그 숫자로 시작하는 번호만 차단.
    `+82 70-…`처럼 국가번호로 온 번호도 `070…`으로 바꿔서 비교합니다.

## 전화 차단 (Android 10+)

삼성 전화 앱은 그대로 쓰고, 이 앱이 **통화 스크리닝 앱**으로 동작합니다.

- 차단 번호의 전화는 **울리기 전에 조용히 끊고**, 부재중 알림도 띄우지 않습니다.
- 시스템이 "차단된 전화"로 기록을 남기면, 몇 초 뒤 **통화 기록에서 지웁니다**
  (부재중·거절·차단 기록만. 실제로 통화했던 기록과 건 전화는 그대로 둡니다).
- 선택: **발신번호 표시 제한** 전화도 차단.
- 켜는 법: ⋮ → 차단 관리 → **전화 차단 켜기** → 허용 → **통화 기록 권한** 허용.
  거부 안내가 뜨면 아래 '제한된 설정 허용'과 같은 방법으로 풀어 주세요.

## 동작 방식

- 기본 SMS 앱이 되면 수신 문자(`SMS_DELIVER`)가 전부 이 앱으로 먼저 들어옵니다.
- 보낸 번호가 차단 목록에 있으면 → **받는 즉시 버림**. 저장·알림·사본 어느 것도 남지 않습니다.
- 차단 목록에 없으면 → 받은문자함에 저장하고 알림을 띄웁니다.
- 번호를 새로 차단하면, 받은문자함에 남아 있던 그 번호의 과거 문자도 삭제합니다.

## 범위 / 한계

- 문자는 통신사가 휴대폰까지 보내기 때문에 **휴대폰에 도착하는 것 자체는 어떤 앱도 막을 수 없습니다.**
  이 앱은 도착하는 순간 버려서 눈에 보이지 않게 합니다. 휴대폰에 도착조차 안 하게 하려면
  통신사의 스팸 차단 서비스에 번호를 등록해야 합니다.
- 이 앱이 기본 앱이 되기 전에 삼성 메시지가 받아 둔 차단 문자(삼성 메시지 '차단 메시지함')는
  삼성 앱 내부 저장소라 이 앱이 지울 수 없습니다. 삼성 메시지에서 직접 지워 주세요.

- **SMS(문자) 전용.** MMS(사진 메시지)는 다운로드·표시하지 않습니다.
- 이 앱을 기본 메시지 앱으로 설정해야 동작합니다(기존 삼성/Google 메시지를 대체).
- 최소 지원: Android 8.0 (API 26) 이상.
- 서명되지 않은 **디버그 APK**이므로, 설치 시 "출처를 알 수 없는 앱" 허용이 필요합니다.

## APK 받는 법 (GitHub Actions)

1. 이 저장소의 **Actions** 탭 → **Build SMS Blocker APK** 워크플로.
2. `android-sms-blocker/` 변경을 푸시하면 자동 실행됩니다. 수동 실행도 가능(Run workflow).
3. 실행이 끝나면 **Artifacts** 에서 `sms-blocker-debug-apk` 를 내려받습니다.
4. 압축을 풀어 `app-debug.apk` 를 휴대폰에 설치합니다.

## "기본 SMS 앱으로 사용하기 위한 액세스가 거부됨"이 뜰 때

Android 13 이상은 파일로 직접 설치한 앱이 기본 SMS 앱이 되는 것을 막습니다('제한된 설정').

1. 설정 → 애플리케이션 → **안심메시지** (앱의 [설정이 안 돼요?] 버튼으로 바로 열 수 있음)
2. 오른쪽 위 **⋮** → **제한된 설정 허용** → 본인 인증
3. 앱으로 돌아와 **기본 앱으로 설정**을 다시 누르기

⋮ 메뉴에 항목이 없으면, 앱에서 기본 앱 설정을 한 번 시도해 거부 안내를 본 뒤 다시 확인하세요.

## 업데이트 설치 (고정 서명 키)

CI가 처음 빌드할 때 서명 키를 한 번 만들어 **GitHub Actions 캐시**에 보관하고, 이후 빌드는 같은 키로 서명합니다.
`versionCode`도 빌드마다 올라가서 **새 APK가 기존 앱 위에 바로 업데이트**됩니다(차단 목록 유지).

- 키는 저장소에 커밋되지 않습니다.
- Actions 캐시는 **7일 동안 빌드가 없으면 지워질 수 있습니다.** 그러면 새 키가 만들어지고, 그 APK는
  한 번만 기존 앱을 지우고 설치해야 합니다(릴리스 설명에 표시됨).
- 저장소 시크릿 `ANSIM_KEYSTORE`(키 파일 base64)를 등록하면 캐시 대신 그 키를 쓰며, 만료 걱정이 없습니다.

## 설치 후

1. 앱 실행 → **기본 메시지 앱으로 설정** 버튼 → 시스템 대화상자에서 허용.
2. 다시 버튼을 눌러 문자 관련 권한 허용.
3. **차단 번호**에 번호를 추가하면 그때부터 해당 번호 문자가 보이지 않습니다.

## 로컬 빌드 (선택)

```bash
cd android-sms-blocker
./gradlew assembleDebug
# 산출물: app/build/outputs/apk/debug/app-debug.apk
```

> Android SDK(platform 34, build-tools 34)와 JDK 17이 필요합니다.
